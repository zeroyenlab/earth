# 地球

**シミュレーションではなく、存在させる。**

計算で「地球っぽい数字」を出すのではなく、
物理と化学だけを置いて、**その上に地球が乗るのを待つ**。

いま見られるもの → **https://zeroyenlab.github.io/earth/**

---

## 置いた法則は4つだけ

| | 法則 | 何が出てくるか |
|---|---|---|
| ① | **ポテンシャル** ── 遠いと引き、近いと反発（Lennard-Jones） | 物がぶつかる・くっつく |
| ② | **にじみ** ── 局所の差を隣との相互作用で均す | **重力**（3次元で 1/r²・実測 −1.984、R²=1.000） |
| ③ | **変換** ── 結合エネルギーの曲線が、融合か分裂かを決める | **種類が増える**・**終わらない熱源** |
| ④ | **保存** ── 外へ出た熱だけが世界から消える | 放射 |

**最下層に置いた上限は「結合エネルギーの曲線」1本だけ。**
`B(m)/m` がある質量で最大になる山型。それだけ。

## 書いていないもの

元素の一覧 / 種類の定義 / 仕事率 / 目的関数 / 報酬 / 難易度 /
層の定義 /「くっつくか」の判定 /「これは1つだ」の判定 / 乱数の種

崩壊が **いつ** 起きるかは、本物の実行時間のジッタが決める。
実際の放射性崩壊も真にランダムなので、そこが一番自然な入口。

## 出てきたもの（書いていないのに出たもの）

- **種類** ── 全部が質量1から始まって、50種類以上に分かれた
- **不活性なもの** ── 曲線の山の近くの質量は結びつかなくなった（希ガスと同じ理屈）
- **分子** ── LJ で束縛された塊。`Oct₂`（質量8が2つ）など
- **層** ── 半径ごとに質量が段になる

## 名前の付け方

この世界では**質量そのものが種類**なので、名前も質量から機械的に作る。
IUPAC が**まだ名前の無い元素**に使うやり方と同じ（118番 = ウンウンオクチウム = Uuo）。

`8 → Oct` / `12 → UnBi` / `21 → BiUn` / 質量8が2つの分子 → `Oct₂`

**人間の周期表とは別もの。** 向こうは陽子の数で並ぶ。ここは質量が種類。
だから質量8を酸素とは呼ばない。

## 台帳（ここが一番大事）

出てきたものが本物かどうかは、**保存則が閉じているか**でしか判断できない。

- エネルギーのずれ ── **±0.000%**
- 質量のずれ ── **+0.0000%**
- 状態の再訪 ── **0**（直近8歩の並びが前に出たことがあるか。周期に入っていない）

ずれが開いたら、そこに嘘がある。過去に6つの台帳の誤りをこれで見つけた
（詳しくは `earth.py` の冒頭）。

## 動かす

```
pip install numpy
python earth.py          # → http://localhost:8766
```

`Ctrl+C` で止めて、もう一度走らせると**続きから**始まる（`state.npz`）。

GitHub Actions の `earth.yml` が20分ごとに区切って回し、
終わったら自分で次の回を呼ぶ。だから置いた人が見ていなくても止まらない。
